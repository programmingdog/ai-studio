# AI Video Studio 管理后台

响应式 Next.js 管理后台，默认端口 `3200`。通过 `NEXT_PUBLIC_API_BASE_URL` 连接模块化单体服务。

当前界面包含：

- 首次登录强制改密
- 运营概览与“服务端零媒体存储”状态
- 提示词、画风、创意类型和自动化流程配置中心
- 设定 → 邮箱配置：选择 HTTP API 或 SMTP，管理 API 地址或 SMTP 主机/端口/加密方式、发件邮箱与密码、服务启停；密码加密保存且不回显，保存后立即生效
- 配置草稿、新版本和 stable 发布
- AI 供应商目录与启停
- WagaAI 实时价格查询弹窗、渠道及参数报价明细、对应模型价格摘要
- 配置中心人民币积分比例；启用后，保存比例或刷新实时价格会按最低可用报价更新模型及分辨率积分
- 四类大模型积分系数（默认 1），独立于基础积分；客户端展示与服务端预扣/结算使用乘系数后的最终积分
- 独立模型测试弹窗，以及创建/查询响应的测试记录页面
- 用户、任务最小元数据、微信支付订单和审计日志

```powershell
npm.cmd run dev:admin
npm.cmd run build --workspace @aivs/admin-web
```

本阶段不修改桌面客户端，也不把客户端媒体或本地用户覆盖配置上传到服务端。

邮箱配置要求服务端已应用 `019_mail_service_config.sql` 和 `020_mail_smtp_transport.sql`，管理员具有 `configs.manage` 权限。首次启用须填写发件邮箱和密码；编辑时密码留空保留原值，修改发件方式、服务器地址、端口、加密方式或发件邮箱时需重新输入密码。只从数据库读取邮箱配置，不再使用同名 `MAIL_API_URL`、`MAIL_API_FROM`、`MAIL_API_PASSWORD` 环境变量。

HTTP API 地址同时支持 `http://` 与 `https://`，例如 `http://211.154.25.178:15686/mail_sys/send_mail_http.json`。填写 HTTP 时显示明文传输风险提示：发件邮箱密码、收件地址与验证码内容不受传输加密保护。此支持不需要额外数据库迁移，不会自动切换现有配置；修改协议或地址仍需重新输入密码。

HTTP 发件兼容旧版 `{ status: true }` 与新版 `{ code: 0, status: true, data: { status: true } }` 响应。默认等待 30 秒；超时或无法确认时不会自动重发，客户端提示用户如已收信可直接填写验证码。服务端日志只保存 `diagnostic_id`、固定结果分类、HTTP 状态、耗时和响应结构，不保存凭据或邮件内容。

宝塔邮局可选择 SMTP，主机 `mail.yuntianxing.net`、端口 `25`、加密 `STARTTLS`（要求服务支持 STARTTLS 并配置可信证书）。使用完整发件邮箱和邮箱密码认证，无需 POP/IMAP。465 端口必须选择 SSL/TLS；不支持明文认证或跳过证书验证。迁移不会自动切换现有 HTTP 方式，保存配置也不会发送测试邮件。
