# 后端与管理后台实施状态 V0.1

> 日期：2026-08-26  
> 阶段：平台基础批次已落地，客户端未改动

## 已完成

1. 新建 `apps/server` NestJS 模块化单体和 `apps/admin-web` Next.js 响应式后台。
2. 建立 MySQL 5.7 兼容迁移体系，迁移文件带 SHA-256 防篡改校验。
3. 建立管理员、角色、权限、供应商、配置版本、任务最小元数据、账本、微信支付订单、公告和审计等核心表。
4. 将现有客户端的默认视频分镜提示词、详细分镜提示词、角色图片提示词、画风目录、创意类型和一键自动化默认流程初始化到服务端配置中心。
5. 完成管理员登录、RBAC、首次登录强制改密、运营概览、配置版本发布、供应商目录和只读业务列表 API。
6. 完成桌面与移动端管理后台布局，以及配置、供应商、用户、任务、微信支付和审计页面。
7. 服务端健康检查明确返回 `media_storage: disabled`；数据库没有 BLOB 媒体字段。

## 数据边界

- 服务端只保存鉴权、配置、路由、远程任务映射、计费和审计所需元数据。
- 服务端不保存任务图片、音频、视频、媒体 Base64、完整提示词或完整结果正文。
- 当前客户端生产调用链完全未修改。
