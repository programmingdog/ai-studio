# 客户端固定日间模式

客户端只提供日间模式，不跟随系统切换暗色主题。图片和视频的内容、二维码及导出视频的黑边不属于界面主题，不做颜色反转。

## 维护方式

- `apps/desktop/src/styles.css` 顶部的 `--ui-*` 变量是公共日间配色：白色/浅灰表面，深色正文，紫色选中态，以及成功、警告、错误和信息的浅底/深字配色。
- 组件原始样式直接使用日间配色，不使用全局 `background: transparent !important` 清除背景。这样弹窗子元素、状态标签、进度条和浮层不会因为漏掉覆盖而退回暗色。
- 主按钮和进度条保留紫色强调；表单、日期控件、滚动条和选择控件保持日间外观。
- `index.html` 声明浅色主题；Tauri 窗口配置固定 `Light` 并设置浅色启动底色。原生窗口配置需重新启动开发客户端或重新打包安装后生效。

## 回归检查

运行 `npm run test:theme --workspace @aivs/desktop`，检查原生/Web 主题、变量引用、色值合法性、语义配色对比度、残留暗色背景和全局覆盖回归。

运行 `npm run build --workspace @aivs/desktop` 验证 TypeScript 和正式前端构建。

启动客户端开发服务后，打开 `/test/light-theme.html` 可检查模型/分辨率选择、场景信息条、日志与日期、任务状态、Agent、设置、引用浮层、账户及自动工作流。样例复用生产 CSS，不访问账户、项目或生成 API，不包含在正式构建入口中。修改组件结构时应同步样例。

实际登录后还应检查项目中的业务页面；静态样例不能替代登录后的端到端流程验证。
